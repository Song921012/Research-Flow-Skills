独立完整绘图任务自主选择了解析场、包含场数据最大误差的初始剖面及局部放大、绝对误差场、RMS 与最大误差收敛图。它区分了 51×101 场采样和各网格共同使用的 65×2049 收敛采样，并明确参考趋势线的含义；未补造耗时或置信区间。

数值核对中，保存的绝对误差与两场差值绝对值的最大残差约为 1.16×10^-16。观测阶只描述该组演示数据，不作为一般性理论保证。独立试用还实际查看了最终 PNG 与 PDF 渲染图，修复了插图刻度和图例边界问题。

## 可以复现的检查

在仓库根目录使用 Python 3.10 或更新版本：

```bash
python -m pip install -r requirements-demo.txt
python examples/render_demo.py
python tests/check_export.py
```

第一条绘图命令只读取已有结果；需要重新生成解析函数演示数据时才运行 examples/make_demo_data.py。Skill 的官方结构校验应在对应宿主的 skill-creator 工具中执行。

## 验证范围

本轮实际绘图使用 Python、NumPy 和 Matplotlib。R 项目、特定期刊投稿、用户真实论文数据，以及只有图片或缺少重复定义等其他输入，尚未逐一实测；后续检查请求记录在 [行为检查案例](../tests/cases.md)。

外部 Vivid、Nature Figure 和 figures4papers 的来源、入口与许可已经核对，本轮没有安装或运行它们的全部脚本。主流程能够使用自身规则完成上述任务；格式校验和这些案例通过，不等于已验证所有科研问题或找到了全局最优图形。
