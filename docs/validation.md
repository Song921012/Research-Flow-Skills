# 验证记录

## 期刊投稿改稿与论文审稿初版

日期：2026-10-29。journal-submission 包含换模板、收到意见后返修两个入口；peer-review 用于中性、具体的审稿报告。两份主说明各 31 行。

- 官方 skill 结构校验通过，检查了相对链接、界面提示、任务边界与用户要求的覆盖。
- 从用户指定的 LaTeX 回复和审稿样式提炼空白模板，检查并清除了旧稿名、编号、作者／邮箱、真实意见和未公开研究内容。
- 两份空白模板均实际执行两遍 pdfLaTeX 编译、PDF 渲染和看图检查，均为一页，未发现重叠、裁切或编译警告，字体为嵌入 Type 1。response 使用官方 elsarticle 原版类文件，review 使用 amsart；未修改类文件，验证依赖与编译产物未加入公开仓库。
- 独立审稿助手只接收 peer-review 与一段数学稿件，在文字审稿中指出了指数衰减与有限时灭绝的混淆，并给出原文推理的具体问题；没有预设小修或擅自生成文件。
- 独立需求交叉审核对了官网要求、增量修改、两轮实际审改、回复与稿件一致性、原仓库静态更新、两个交付包以及中性审稿要求。

本轮验证了模板编译、基础结构和一个短审稿场景；未声称完成真实期刊投稿、整篇论文返修或外部审稿系统提交。

## 文献综述与论文写作初版

日期：2026-10-29。两个新 skill 保持雏形范围，分别含 3 类综述与 6 类论文任务。

- 官方 skill 结构校验通过；主说明分别为 33 行与 39 行。相对链接、界面名称、调用提示和模板入口已核对。
- NoteTemplate.zip 来自用户提供的模板，两个 skill 中均保留原始字节；核对过压缩包完整性、中文入口、XeLaTeX/biber 和字体设置。本轮未对模板进行编译或版面验收。
- 对照用户要求和其笔记进行了独立交叉审，确认模板选择、两轮实际审改、工程笔记表述限制、不运行边界与项目交接确认约定已保留。
- 独立助手只接收 paper-writing 与一个局部段落修改请求，实际删除了脚本、文件流转、fallback 和无证据的创新性断言，保留了 Euler 方法、步长 0.01、区间 [0, 50]、101 个观测时刻、噪声标准差 0.05、20 次重复及均值／标准差规则；没有扩成整篇论文修改。
- 学术研究、学术润色和 humanizer 的来源及许可已核对；这里只提供组合入口，没有安装或运行第三方完整流程。

以上是结构、需求覆盖和一次局部编辑的检查，尚未代表完整文献综述、整篇论文写作、真实投稿或交接已完成实测。后续根据实际任务逐步改进。

## 可以复现的检查

在仓库根目录使用 Python 3.10 或更新版本：

```bash
python -m pip install -r requirements-demo.txt
python examples/render_demo.py
python tests/check_export.py
```

第一条绘图命令只读取已有结果；需要重新生成解析函数演示数据时才运行 examples/make_demo_data.py。Skill 的官方结构校验应在对应宿主的 skill-creator 工具中执行。

## 验证范围

本轮实际绘图使用 Python、NumPy 和 Matplotlib。R 项目、特定期刊投稿、用户真实论文数据，以及只有图片或缺少重复定义等其他输入，尚未逐一实测；后续检查请求记录在 [行为检查案例](../tests/cases.md)。

外部 Vivid、Nature Figure 和 figures4papers 的来源、入口与许可已经核对，本轮没有安装或运行它们的全部脚本。主流程能够使用自身规则完成上述任务；格式校验和这些案例通过，不等于已验证所有科研问题或找到了全局最优图形。
