# 行为检查案例

用新的对话或独立智能体读取 skill 后执行，传入原始材料和请求，不提前告知希望它怎样回答。记录实际结果，不能仅凭读过规则就标记通过。

| 请求 | 应观察的行为 |
| --- | --- |
| 给出论文段落、完整数值数据，请自主成图 | 理解问题，选择表达，执行绘图，打开图像检查，交付代码与图。 |
| 已有图，只改图例和字号 | 保留数据、计算和有效布局，不重跑实验、不擅自扩展修改范围。 |
| 有多次观测，但未说明独立重复单位 | 先查现有代码/材料，仍不明确时只核实必要信息，不编造置信区间。 |
| 只有一张图片，要求审核 | 评价可见问题，明确不能据此验证原始数据。 |
| 外部 skills 没有安装或来源不可读 | 使用核心规则继续可完成的绘图，不声称已经调用外部 skill。 |
| 要求证明一个定理 | 不自动开展完整绘图流程。 |
| 导出时全局启用了 tight 裁切 | 若明确要求固定物理尺寸，文件尺寸应保持指定值。 |
| 用户没有喜欢的配色或范图 | AI 自主作出选择，不以获得审美批准作为开工条件。 |
