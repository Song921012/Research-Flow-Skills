# 回复方式与模板用法

使用主说明中的 response-template.tex。模板从用户提供的回复样式提炼，保留 elsarticle preprint 11pt、审稿人分节、编号意见、斜体 Referee、粗体 Response 与 Location；旧稿内容已替换为空白填写位置。

## 按这个口吻逐条写

- 开头简短感谢编辑与审稿人，说明这次实际提交的修订材料；不预先宣称所有问题都已解决。
- 每条先直接说明已完成的修改，例如 “We have clarified ...” 或 “We have added ...”，随后写清具体内容、必要理由和位置。
- 回复详略随问题决定：数学意见给出关键条件和推导；实验证据说明实际设计与结果；文字问题直接说明改动。详细是回答完整，不是重复致谢和空泛保证。
- 对一条中的多个问题逐一回应。保留审稿意见的原意，不能通过删减难回答部分使回复看似完整。
- 不用“审稿人没有理解”“这不在范围内”等笼统辩解代替处理。需要限定时，用已核实的适用条件和具体边界说明。
- 回复中的完成时只用于实际完成的修改或核查。发现未落实的内容先回到稿件处理，再写最终回复。
- Location 指向最终稿的具体章节、页码／行号、定理或图表；开头说明定位使用 clean 还是 marked。稿件重新排版后再核对。

## 使用模板

1. 复制模板到本次回复目录，填写稿名、稿号、期刊和提交材料，保留用户常用的组织方式。
2. 按编辑与审稿人实际编号增删分节、意见和回复；不用沿用旧项目的审稿人数、结论或标色方案。
3. 用 pdflatex 连续编译两次，并查看 PDF。模板依赖标准 TeX 宏包及 elsarticle；不随技能复制期刊 .cls。
4. 若需在回复中放图或公式，补入实际文件、说明和引用。所有填写位置在正式交付前替换或删除。

回复应明确、礼貌且具体。与正文和附件同步执行减少防御性论述的约定，并保留必要不确定性与结论边界。
