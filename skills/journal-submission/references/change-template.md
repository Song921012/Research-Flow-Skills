# 投稿换模板

**一句话调用：**“准备改投这个期刊，请先读官网要求，替换 LaTeX 模板并准备投稿材料，科学内容保持不变。”

## 怎么做

1. 读当前正文、附件、Bib、图和目标期刊信息。保留源版本，在新目录适配；项目已选定的模板继续使用，没有目标期刊或模板选择时才问必要问题。
2. 打开目标期刊官网当前作者指南、LaTeX 模板说明及附件／图表要求；有编辑信或投稿系统明确要求时一起核对。简短列出本阶段应交的文件，并附官方链接和核查日期。
3. 核对文章类型、篇幅与摘要、标题页／匿名要求、章节与必要声明、引用样式、正文与附件关系、图表规格，以及 PDF／LaTeX／Bib／图片如何提交。具体要求从当次指南获取，不凭别的期刊或旧经验套用。
4. 必要时查找该刊近期可下载的同类型论文，学习章节、声明、图注和引用的安排。已发表成品版式仅作参考，不能代替官方规定的投稿模板。
5. 使用官方或用户指定且适用的模板，不修改 .cls。适配命令、定理、公式、引用、图表与元信息，保留科学内容和有效修改；Bib 继续作为引用来源。
6. 在当前任务允许时编译并实际查看最终 PDF：引用和交叉引用是否正确，公式、图表、分页、字体是否正常，必要栏目是否齐全。只替换文档类或编译成功，都不能代替这些检查。
7. 按真实上传项目组织文件；marked／unmarked、正文与附件是否分开、是否需要合并，以本刊当前要求为准。正文与附件所有需要的源文件和图都应有清楚对应。

## 交付

交付可提交的稿件目录或压缩包，附简短的材料清单、官方指南链接和实际完成的检查。只换模板的任务不重跑实验、不重写正文、不自动启动审稿意见回复或复现仓库更新。
