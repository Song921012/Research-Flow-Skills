# 科研图示

目标是让读者看懂研究对象、关键想法与关系，并获得精致、可继续修改的图。先确定图要解释什么，不把所有内容一律变成方框串联。

## 从故事构思图

1. 阅读相关正文、公式、已有图和研究方案，确认图放在哪里、服务哪句话。先用一句话说清核心信息。
2. 找出对象、输入、关键操作、输出以及它们的关系。区分顺序、并行、依赖、反馈、比较和验证；每条箭头都应有明确含义。
3. 核对哪些模块是本文创新，哪些是已有方法；只按材料突出贡献。训练、推断、实验验证若不同，应清楚分区；没有这些阶段时不硬加。科学子任务或关系未在材料中确定时先查依据，确需补充的标为建议，不能把自主构图变成悄悄增改研究计划。
4. 按资料卡读取相关 skill，并查看同类问题的实际范图和图注。学习信息组织、视觉层次、局部放大与符号表达，不能只看摘要或凭期刊名选图。
5. 按科学关系选择结构。模型总览可用对象与模块示意，算法可用输入输出与关键运算，机制可用交互和反馈，研究计划可用并行任务与共同验证；有依据时将结构示意和少量数学式结合。
6. 复杂新图比较少量不同表达思路，由 AI 自己选定推荐方案。先在内部写清模块、关系和阅读顺序，再安排颜色与装饰；不要求用户具备选图能力。

## 按使用场景调整

| 场景 | 重点 | 默认源文件 |
| --- | --- | --- |
| 报告中的流程图 | 远距离可读，一次突出当前要讲的关系；复杂图可逐步展开 | 当前汇报的原生对象，PPTX 或 Beamer/TikZ |
| 论文方法、模型或算法总览 | 核心机制准确，模块、符号、图注自洽，按实际栏宽仍易读 | 按需要选 SVG、TikZ、PPTX 或 draw.io，并导出合规成图 |
| 基金技术路线图 | 科学问题、研究任务、方法与验证对应，区分拟开展工作与已有基础 | PowerPoint 原生可编辑对象及正文导出图 |

同一项研究可以共用科学关系和符号，但报告、论文与基金各自调整信息密度和布局，不能只缩放同一张复杂图。明确要求某种文件格式时优先满足，不以其他格式冒充。

## 实际制作与修改

- 制作 PowerPoint 时先读取当前环境的 Presentations/PPTX skill，使用其可用工具；对其他格式采用已验证可用的编辑、编译与渲染方式。
- 文字、连接线、核心形状和精确关系保持可编辑。整张位图或整张 SVG 插入 PPT 不等于所有对象可编辑；局部图像素材与可编辑核心对象分别说明。
- 核心数学式、箭头和真实数据用可核对的源文件构造。需要概念性位图素材时可调用可用图像生成能力；生成图不能替代精确公式、数据和算法关系。
- 用对齐、间距、字重、少量有语义的颜色和适当留白表达层次。对象图标须帮助理解；不要用无意义图标、长段落和重复边框填满画布。
- 长标签先精炼、换行或调整局部布局；不靠一味缩小字号解决。检查颜色在灰度和常见色觉差异下是否仍有文字、形状或线型辅助。
- 查看实际导出的整图和关键局部，按目标尺寸检查；有论文或申请书时检查嵌入后的效果。发现箭头含义或连接错误时先修内容，再修外观。
- 局部微调保留已有内容、关系、素材与主风格。重画已有数据图时调用 paper-figures，样式修改不重跑实验。

## 交付

按验收卡检查后交付一套推荐成图、对应可编辑源文件和需要的图注或简短说明。保留必要素材、字体或编译依赖说明；源文件与最终导出保持一致。参考来源和修订记录放在工作资料中，正式图中只保留有用的学术信息及必要署名。
