# 可组合的外部 skills

以下是已核实的候选来源；用户以后指定其他仓库或版本时，以用户选择为准。按本次任务读取相应入口，不为了一次任务载入整套流程。

| 需要做什么 | 来源与入口 | 本流程如何使用 |
| --- | --- | --- |
| 查文献、形成研究综述 | [Academic Research Skills / deep-research](https://github.com/Imbad0202/academic-research-skills/blob/main/deep-research/SKILL.md) | 帮助查证与综合，输出格式服从本任务 |
| 起草学术论文 | [Academic Research Skills / academic-paper](https://github.com/Imbad0202/academic-research-skills/blob/main/academic-paper/SKILL.md) | 帮助组织论文和论证，不替代用户选定模板 |
| 严苛审稿 | [Academic Research Skills / academic-paper-reviewer](https://github.com/Imbad0202/academic-research-skills/blob/main/academic-paper-reviewer/SKILL.md) | 检查稿件后实际改稿，避免只给评分 |
| 学术措辞与逻辑润色 | [research-skills / academic-writer](https://github.com/drarunmitra/research-skills/blob/main/academic-writer/SKILL.md) | 保持学术语气和证据边界，不机械套固定段数 |
| 语言去空泛、去机械表达 | [humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md) | 轻量编辑，保留数学、事实、引用和必要术语，不改成口语或宣传文案 |
| 论文图 | [本仓库 paper-figures](https://github.com/Song921012/Research-Flow-Skills/tree/main/skills/paper-figures) | 先读论文与数据，自主选图，画图、看图、修改和审核 |

已安装就通过宿主支持的方式使用；未安装但可访问时读取入口及所需参考文件，再应用相关做法。链接本身不代表安装、调用或完成验证。原作者和已核实备用均不可用时按当前技能继续工作，简短说明限制。

用户当前要求优先：简体中文沟通、指定 LaTeX 模板、论文不含工程笔记式表述、数学严谨性及任务范围。不自动继承外部流水线的逐阶段审批、APA 格式、固定 Introduction 段数或其他不适用约定。

## 原作者优先，用户 fork 备用

优先读取原作者来源的安装或仓库。确认原仓库删除、所需入口撤下且没有适用迁移入口，或当前确实不可用时，再用下表备用仓库中的相同路径。临时限流不等于删库；定期更新备用仓库不改变来源优先顺序。

Academic Research Skills 的备用仓库为 [Song921012/academic-research-skills](https://github.com/Song921012/academic-research-skills)，对应入口仍为 deep-research/SKILL.md、academic-paper/SKILL.md 和 academic-paper-reviewer/SKILL.md；使用相关功能时保留 shared 等实际需要的共享资源。

这里没有把中文 Humanizer-zh 当作英文 blader/humanizer 的相同副本。英文 humanizer 和 academic-writer 暂无已核实的用户备用地址；不可用时按本流程继续独立处理，并说明实际使用范围。原许可与来源归属保持不变。
