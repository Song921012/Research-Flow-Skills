# 有一个想法：查前人研究

**一句话调用：**“按文献综述流程查一下这个想法，用我的中文 NoteTemplate 整理。”

## 怎么做

1. 从已有描述提炼科学问题、核心方法和可能的新意，必要时把含混词换成可检索的术语。
2. 查最接近的原始研究、奠基工作与近期进展，沿关键论文追溯引用。检索范围跟着问题走，不为了数量收集不相关文献。
3. 按研究路线比较问题、假设、方法、理论或数据证据和局限，解释与当前想法的重合与差别。
4. 判断哪些已有答案，哪些是真正可继续研究的问题，哪些暂时只是没有检索到。提出下一步最值得查或验证的事情。
5. 用 NoteTemplate 的中文版本写成连贯综述，更新 references.bib；重要判断有对应引用。

## 交付

- 中文 LaTeX 源文件、Bib 和模板所需文件；可以编译时交付 PDF 并检查版面。
- 沿用模板已有结构与风格，章节按研究问题安排，不强制固定目录。
- 简要说明主要结论、关键文献与证据不足之处；不把检索操作日志写进综述正文。
- 无法获取全文、编译器或字体时，如实说明具体缺口，保留可继续工作的源文件。
