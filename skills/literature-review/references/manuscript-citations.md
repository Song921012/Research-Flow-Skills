# 给论文补文献

**一句话调用：**“给这部分 Introduction 补好文献。”或“查一下这个方法／数学结论的依据，直接放到论文里。”

## 怎么做

1. 先读相关段落、符号定义、上下文和已有 Bib，确认需要支持的是哪一句话。
2. 查直接相关的原始来源。方法要核对适用范围；数学结论要核对假设、结论强弱、定理或页码位置。
3. 把文献融入原稿论证：背景为什么重要、前人如何处理、还有什么不足、本文为何值得做。Introduction 用来引出研究，不提前复述整篇结论。
4. 修改对应段落、引用键和 Bib，避免重复条目。现有键被别处使用时保留或同步更新所有引用。
5. 检查引文是否真的支持相邻论断。来源只支持较弱结论时，收窄表述，不能用一串引用代替论证。

## 交付

直接交付修改后的论文段落与 Bib，简短说明新增来源及改动位置。默认不另外生成中文 LaTeX 综述或独立报告。缺少论文源文件时，先提供可插入的文字、引用位置和 Bib 条目。
