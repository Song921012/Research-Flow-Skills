# 已有方法：找生物应用和数据

**一句话调用：**“这个方法可以用在哪些有意思的生物问题上？优先高质量论文和开放数据。”

## 怎么做

1. 先读方法的输入、输出、关键假设、能解决的问题和不能解决的问题。
2. 优先搜索传染病动力学、生态动力学、药物动力学，也保留确实更适合的其他生物场景。
3. 从生物问题出发，找尚未充分解决的机制、预测、干预、参数或观测问题，解释为什么现有方法有机会带来新认识。
4. 沿代表论文找数据原始入口；核对下载或申请方式、开放程度与使用条件。检查变量、观测频率、样本量、缺失、干预与方法假设是否相容。
5. 区分开放实测数据、合成数据、仅有图中数据、需要申请的数据和不可获得的数据。不能把“论文说数据可用”直接当成已拿到可用数据。
6. 选少量最值得继续的方向，说明最小验证方案、预期生物意义、主要困难和 AI 的推荐顺序。

## 交付

每个候选讲清楚：生物问题、代表文献、为什么适合当前方法、数据入口与实际可获得程度、第一步能验证什么。优先推荐有科学价值且可落地的场景；期刊名气只作为辅助。默认直接在对话中整理，不自动写独立 LaTeX 报告，也不自动开始新实验。
