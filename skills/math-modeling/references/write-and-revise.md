# 写作与修改

## 沿用模板，学习写法

使用用户指定的 LaTeX 模板。给了参考 PDF 就先读组织方式、论述节奏、摘要与图表写法；扫描版先识别文字，再查看版面。只借鉴写法，不搬用研究内容、结果或未经引用的论述。

## 用户常用的论文组织

- **摘要：**第一段交代背景、总体方法和研究对象；接着按实际子问题分别概括方法、关键结果和意义。问题数量决定段数，不固定为五段。凝练表达，少量加粗真正重要且有依据的创新和结果。
- **问题重述：**分背景和问题提出，准确列出各问要求。
- **问题分析：**逐问说明难点、可用信息与解决思路。
- **模型假设：**列出真正用于推导或计算的假设与依据。
- **符号说明：**符号、下标、单位与全文和代码结果一致；按数学含义选符号，不以换字母替代来源说明。
- **模型与结果：**详细交代建模、求解、验证及结果解释。优化模型用明确数学表达，推导说明条件和关键步骤。结果应回答题目，而不只罗列运行数字。
- **模型评价与改进：**依据实际证据说明优点、适用边界和可能改进，避免空泛自夸或反复防御性解释。
- **附录：**通常以支撑材料列表和用途说明为主；比赛要求源代码、AI 使用记录或其他内容时，按规定补齐。

实际目录和篇幅服从当届比赛与用户模板，不为套结构增加无用章节。

## 至少两轮实际审改

1. **第一轮：**作为评委检查是否答全问题、数学定义和推导是否正确、模型与计算是否一致、结论是否有数据支持。修正问题，再核对受影响内容。
2. **第二轮：**检查科学叙事、术语、摘要、引用、图文对应、匿名信息和版面；按需用 humanizer-zh 润色，再复查事实、数字、公式和限定。
3. 两轮都检查工程笔记式表达和不必要的防御性论述。保留必要的数学、参数、离散、噪声、优化与统计细节，不把“精炼”变成删去科学依据。
4. 用户已认可内容，只要求最后润色或微调时，保留主体与结果，修正指定部分及确有依据的问题，不大修整篇论文。

完成后编译并查看最终 PDF，核对引用、公式、图表、分页与导出；将内部评审和修订记录留在 Work，不混入论文正文。
