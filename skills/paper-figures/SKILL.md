# 论文画图

先读[统一语言约定](references/language.md)。根据本次范围和下文指引读取所需资料；同一任务内已读的同版资料直接复用。

把已有结果转成忠实、易读、协调的论文图，由 AI 承担选图和审美判断。
先完成科学表达与必要检查，再精修外观；用户反馈用于校准，无需逐轮审批。
以用户本次明确要求为准，按以下四步推进；局部改图保留已有有效设计。

方法流程图、模型总览与整套 Beamer/PPT 汇报交给 research-presentation；本 skill 继续负责真实数据图。混合图按内容协作，由当前作品的主流程统一符号、配色和最终检查，不因图出现在 PPT 中就改用概念插图方式。

## 开始前读取

- 读[协作偏好](references/preferences.md)，确认自主判断和修改范围。
- 新图、表达调整或遇到具体绘图问题时，读[资料使用索引](references/resources.md)；简单续改沿用当前项目已核实的资料。
- 新图或表达需要调整时，读[选图方法](references/selection.md)。
- 需要外部技能补充时，读[其他绘图 skills](references/optional-skills.md)。
- 审核与交接前，读[检查与交接](references/review.md)。
- 需要复用尺寸、导出或记录功能时，先读[绘图辅助脚本](scripts/figure_io.py)的实际接口。
- 核心流程须能独立执行；外部资源缺失时采用自带方法，不虚构调用或运行结果。

## 第一步：读论文和数据，理清需求

1. 查看提供的论文段落、数据、代码、已有图与项目说明，有什么先用什么。
2. 判断任务是检查、局部修改还是新绘图；保护用户已有修改，记录本次范围。
3. 将论文主张转成每张图需要回答的问题，判断已有证据支持什么结论。
4. 核对变量、单位、数据形状、时间与空间顺序、误差定义、重复及配对关系。
5. 从现有材料补齐信息；只有影响科学解释的关键内容仍不明确时才询问。
6. 简短确定本次图的作用与数据来源，不强求用户填写完整表格或提供认可范图。

## 第二步：查资料、找范例、构思图形

1. 从索引选择相关理论、相似研究的论文图、图形示例或源码，说明借鉴什么。
2. 根据比较目的和数据结构选择图形，保留任务需要的范围、失败结果和不确定性。
3. 复杂新图按需比较有实质差异的方案，自己选定推荐版本；简单修改直接完成。
4. 判断主次、面板顺序、标注和最终尺寸，让同一方法的视觉含义保持一致。
5. 使用外部 skill 前确认准确来源和当前可用性；默认只链接受限的 Vivid 资料。
6. 不固定配色、字体、模板或候选数量，不为漂亮的模板制造数据或无关面板。

## 第三步：画图、看图、改图

1. 沿用项目合适的 Python、R 或其他绘图方式，从实际数据实现方案。
2. 保留数据来源及必要处理；平滑、筛选、归一化和区间计算须有依据并说明。
3. 将样式与结果计算分开；只改样式时重画已有结果，绝不重跑实验或训练。
4. 执行绘图代码，打开真正导出的图，按论文最终尺寸检查可读性与布局。
5. 针对发现的问题修改并重新查看，直到必要问题解决；避免无目的反复美化。
6. 有论文时检查嵌入效果；没有图像查看能力时说明视觉部分未核验，继续完成可做的工作。

## 第四步：审核与交接

1. 分开完成数据对应核对与视觉检查，按检查文件记录实际结果。
2. 核对图注、单位、系列、尺度、区间含义、处理说明和导出要求。
3. 交付一套推荐成图、可运行代码、明确数据指向、必要运行说明和简短图注。
4. 按用途提供可用格式；只修改指定部分时沿用原交付形式，不额外扩大工作。
5. 简要说明选择理由与已完成检查；未运行、未查看或缺少原数据的部分如实说明。

## 科学表达始终保留

- 从真实结果绘制数据图，不用图像生成补造曲线、热图数值或实验现象。
- 区分精确解与数值参考解；保留误差定义、比较条件和有意义的失败信息。
- 对数轴、参考阶、插值、截断和聚合均需适合数据，不能通过处理制造优势。
- 区分独立重复、相关观测及配对实验；区间含义须与实际计算一致。
- 可比面板保持相同的颜色含义与可比尺度；需要不同尺度时明确标出。
- 只有图片时，审核限于可见内容，不能声称完成原始数据核对。

## 积累有效经验

完成数据核对和成图检查后，在当前项目保存可复用图、代码、适用问题及选择理由。
用户反馈可补充偏好；AI 自选案例不自动代表用户认可，更不形成所有任务的固定风格。
只保存有用的简短记录，私有数据、论文和图片不得自动发布到公共仓库。
