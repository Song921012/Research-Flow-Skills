# 一份可以重画的演示

这里使用公开可复现的解析函数数据，演示“读已有结果 → 选择图形 → 绘制 → 检查”的实现。它不包含私人研究数据，也不代表某个算法的论文实验。

参考函数是零边界的一维热方程解析解：

\[
u(x,t)=e^{-\pi^2 t}\sin(\pi x)+0.3e^{-9\pi^2t}\sin(3\pi x).
\]

近似值是在空间网格上取函数值后做分段线性插值；没有训练模型，也没有把插值包装为新的 PDE 求解器。空间和时间均为无量纲坐标。

- `data/fields.csv`：51 个时刻、101 个空间位置；参考解、12 个网格单元的插值及绝对误差。
- `data/convergence.csv`：12、24、48、96 个单元；在相同的 65×2049 时空采样上计算 RMS 和最大误差。
- `render_demo.py`：只读取已经保存的 CSV 并绘图。修改样式运行这个脚本即可。
- `make_demo_data.py`：需要重新生成演示输入时才运行。

参考解与插值图共享颜色映射；误差图有独立色标；收敛图使用实际 h 与 RMS 值，虚线为标明的二阶参考趋势。导出宽度为 17.8 cm、高度为 12.6 cm，保留 PDF、SVG 和 300 dpi PNG。

从仓库根目录运行：

```bash
python -m pip install -r requirements-demo.txt
python examples/render_demo.py
```
